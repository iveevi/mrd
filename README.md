# Mr.Dillo's Middleman for 3D Models

Are you tired of writing your own 3D model representations for every graphics project? Try Mr.Dillo's middleman for 3D models! We take care of serializing and deserializing 3D models, and in return you get a feature-rich 3D representation with geometry, animation and skinning, and texturing all in one package.
